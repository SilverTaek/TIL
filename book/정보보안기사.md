## 1과목 시스템 보안

```
#01 리눅스에서 실행중인 프로세스를 조회하는 명령어는 ? 
$ ps -ef
: 프로세스 목록(현재 실행중인 프로세스)을 전체 포맷으로 보여준다.
주요 칼럼으로는 UID,PID,PPID,C,STIME,TTY,TIME,CMD가 있다.
$ file
: 파일의 실제 타입을 매직넘버 기반으로 판별
ex) ASCII text.txt
$ lsof
:열려 있는 파일(= 파일 디스크립터, FD) 목록을 보여준다.
* 리눅스에서 파일이란 소켓/파이프/디바이스도 포함이라 네트워크/포트 점검에도 사용
$ vmstat
: 가상메모리/프로세스/CPU/IO 상태를 한 번에 요약해서 보여준다.
```

```
#02 리눅스 프로세스 중 좀비 프로세스를 탐지하는 명령어는 ?
$ ps -ef | grep zombie : 프로세스 목록 중 zombie 라는 문자열이 있는 줄 찾기
$ ps -ef | grep defunct : 좀비 프로세스는 명령어 칼럼에 <defunct>로 표시되는 경우가 있어 해당 문자열이 포함된 프로세스를 찾기
$ top | grep zombie : top 화면 출력에서 zombie 라는 단어가 있는 줄을 찾기
$ top | grep defunct : top 화면 출력에서 defucnct 라는 단어가 있는 줄을 찾기(top은 보통 <defunct>를 직접 보여주지 않는 경우가 많음)
```
